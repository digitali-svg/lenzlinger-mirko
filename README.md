# Lenzlinger Mirko — site vitrine

Site statique (HTML/CSS/JS, sans backend) pour la boutique Lenzlinger Mirko.

## Aperçu local

Ouvrir `index.html` directement dans un navigateur, ou lancer un petit
serveur local depuis ce dossier :

```bash
python3 -m http.server 8000
```

puis aller sur `http://localhost:8000`.

## Pages

- `index.html` — Accueil
- `produits.html` — Catalogue (6 emplacements produits à compléter)
- `a-propos.html` — Présentation de la marque
- `contact.html` — Formulaire de contact
